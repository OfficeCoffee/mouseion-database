***Key difference of the physical model compared to the conceptual and logical models:***

**conceptual model:** The most basic view of the database, used to put your ideas on paper and easily understand what is needed.

**logical model:** The in between view of the database, used to visualize what your database will actually look like and how it should be organized.

**physical model:** The in depth view of the database, used to see exactly how your database should look and how it should be implimented.

***What are the common data types***: 

**Integer (int):** Stores whole numbers without decimals.

**Decimal (numaric):** Stores exact decimal numbers.

**Varchar (varchar):** Stores variable-length text up to a defined character limit.

**Char (char):** Stores a specific number of characters.

**Text (text):** Stores a large number of characters or text.

**Date (data):** Stores calendar dates in a YYYY-MM-DD format.

**Time (time):** Stores times in a HH:MM:SS format.

**Datetime (TIMESTAMP, DATETIME):** Stores both data and time.

***Terms***: 

**Default values:** The value or type that the column can be or hold.

**Null values:** Determines if the column can be null (empty) or not.

**Check constraints:** A rule that ensures data meets a specific condition before it can be saved.
